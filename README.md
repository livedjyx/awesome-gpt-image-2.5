## 使用方式

| 类型 | 输入方式 |
|---|---|
| G：直接生图 | 文字；部分条目需给定文案或数据 |
| R：参考图引导生成 | 参考图片与文字 |
| E：编辑现有图片 | 待编辑图片、必要素材与修改要求 |
