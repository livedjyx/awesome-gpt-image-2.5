## 提示词

```text
使用输入图 1 的原创指南针，创作方形的毛绒抱枕产品概念。保留圆形金色外圈、顶部小环、深蓝盘面、四个白色方向刻度、红白双色指针且红端向上，按同一正面略俯视方向展示。所有部分转为短绒织物与软填充，针形为安全的扁平布贴，缝边沿圆周和小环自然连续；柔软外缘略鼓起，仍一眼识别为指南针。放在暖白布面上，柔和棚光，没有金属玻璃硬壳、数字、字母、额外抱枕或水印。
```

## 检查

软体体积成立；绒毛不吞没轮廓

圆环、顶部小环、四个白色刻度与红白指针的位置对应输入，红端朝上，材质转为短绒和布贴，缝边完整。
