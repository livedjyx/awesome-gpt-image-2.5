## 提示词

```text
设计一张横幅 3:2 的人物短句分享卡，风格为原创扁平矢量感插画。背景温暖浅米色，使用深绿色、陶土橙与少量灰蓝，线条干净，色块简洁。

画面左侧约三分之一是一位虚构的成年园艺志愿者半身插画：短发、戴圆框眼镜，穿浅色上衣和深绿色园艺围裙，手里托着一小盆刚发芽的植物，神情安静。人物形象不要模仿任何真实名人。右侧约三分之二是一段大字号中文短句，按自然语义分为三行，采用清楚的现代中文黑体。

短句逐字写为：「把每天的小照料，留给正在生长的事物。」只出现一次。右下角只放一行小字：「林禾｜园艺志愿者（虚构）」；左上角用很小的字写「日常观察」。

文字区域四周留白，植物叶片不遮挡文字，句号与括号完整。画面保留插画平涂风格，不使用照片、三维塑料质感、额外标语、品牌或水印。
```

## 检查

短句准确；署名为自拟虚构角色
