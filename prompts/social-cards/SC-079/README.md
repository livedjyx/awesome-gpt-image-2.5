## 提示词

```text
使用输入图 1 作为唯一成年人物身份参考，制作横幅 3:2 的复古旅行照片拼贴手账卡。保留短卷发、眼镜、面部特征。暖米纸面上放三张照片：左侧一张较大的河畔人物半身照，穿灰蓝外套；右上是河边石阶与树影；右下是一本合拢笔记本和一杯茶的桌面细节。照片边缘略旧，用少量半透明胶带固定，光线和胶片色调统一。照片之间一张小便笺只写「沿河走走」，右下小字「一日记录」。便笺和胶带不遮脸，不添加新人物、印刷书名、邮戳地址或水印。
```

## 检查

人物可识别；便笺不遮挡主要面部

三张旅行照片完整，人物短卷发、眼镜与面部延续输入，两处指定文字可读；边角少量植物装饰未遮脸。
