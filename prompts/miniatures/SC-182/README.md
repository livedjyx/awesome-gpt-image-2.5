## 提示词

```text
生成一张方形等距三维微缩房间图，场景为兼做自行车维修的阁楼工作室。房间置于独立方形底座上，使用固定轴测视角，从左前上方看向房间内部。切去正面和左侧墙体以及屋顶，保留后墙、右墙与两段斜屋顶木梁，切口平整、连续。

后墙靠左是一张木质维修台，台面只放工具盒和小台灯，墙上挂整齐的小型扳手。房间中央偏左是一辆完整的深绿色城市自行车，固定在独立维修支架上，两个车轮、车架和车把清楚。右侧靠墙是一张窄休息长凳，下方放一个收纳箱；右后角有一扇小阁楼窗，窗外不绘制复杂风景。

使用柔和的三维黏土模型与木材质感，暖木色、灰白墙面和少量深绿色。柔光来自左上方，阴影轻微且方向一致。所有家具、墙角和底座遵循同一组轴测方向，不出现摄影镜头式的近大远小或倾斜地板。

工具与房间比例合理，自行车两个轮子完整可见，物体不穿墙。背景为干净的浅米色留白，不加入人物、文字、品牌、水印或第二辆自行车。
```
