## 提示词

```text
制作一张竖幅 2:3 的手绘线稿步骤卡，讲解简易种子纸的制作，适合初次尝试纸艺的读者。白色纸面，黑色细线，少量叶绿与浅棕点色，整洁的 2×2 四格布局。

顶部标题仅为「制作一张种子纸」。标题下方用小图标列出材料，并只写「废纸、水、小种子、网筛、布」。下方四格按左上、右上、左下、右下的顺序编号 1、2、3、4，各格仅包含对应插图和以下文字：
1：「撕纸浸泡」；画撕碎的普通无涂层纸浸在水碗中。
2：「捣成纸浆」；画用手动工具轻轻捣散湿纸，不出现电动机器。
3：「混种铺筛」；画少量种子撒入湿纸浆，混合后在平放的网筛上铺成薄层。
4：「吸水阴干」；画薄纸浆层转到布上吸水，并平放在通风阴凉处干燥。

四格中的碗、网筛与纸张大小应连续一致。用单向小箭头引导阅读，编号和短标题准确，不加入没有给出的步骤、具体发芽承诺、复杂长文或水印。底部只放一句：「干燥后可种入土中，效果因种子与养护而异。」
```
