## 提示词

```text
使用输入图 1 的原创成年女性作为唯一身份参考，创作横幅 3:2 的三套城市骑行日常造型板，时装摄影，三个完整全身人物横向并排且均是同一人。保留短卷发、眼镜、脸型与体型。左套：橄榄绿短夹克、米色九分裤、白色平底鞋；中套：浅蓝衬衫、深灰直筒裤、灰色平底鞋；右套：陶土红运动外套、藏蓝束脚裤、黑色平底鞋。三个自然站姿略有变化，衣物贴合真实身体和重力，裤脚收敛不过分宽大，统一浅灰棚拍背景。不画自行车、头盔、额外人物、文字或水印。
```

## 检查

身份一致；服装差异明确

三套全身穿搭的人物身份、发型与眼镜一致，橄榄绿、浅蓝和陶土色上装及配套裤鞋对应提示。
