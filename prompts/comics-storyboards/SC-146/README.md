## 提示词

```text
绘制一张竖幅 2:3 的原创四格日常漫画，动漫赛璐璐风格，干净线稿与温暖平涂色彩。用 2×2 等大分格，阅读顺序为左上、右上、左下、右下，各格左上角只标一个数字 1、2、3、4，无对白。

主角是一位虚构的成年修理学徒，短黑发、圆脸、青绿色工作围裙、米色短袖，全程保持同一人物、服装和年龄。场景是木窗旁的小修理台。核心道具是一只黄铜碗形风铃，风铃下方有深蓝色长方形纸签。

第 1 格：学徒在工作台上检查风铃，发现铃体内的小木槌脱线掉在桌上，表情专注。第 2 格：近景表现学徒用一根细绳重新穿好小木槌，连接到铃内，动作与结构可理解。第 3 格：学徒把修好的风铃挂到窗边，窗外一阵风吹来，深蓝纸签突然扬起，人物微微惊讶。第 4 格：风铃的小木槌轻碰铃壁，以两条小动作线表示轻响，学徒站在窗旁满意地微笑。

保持黄铜铃体、深蓝纸签和木槌在四格中的形状、颜色与数量连续。情节通过动作和表情表现，不写拟声词、标题、旁白或水印。不要添加第二位人物、额外风铃或不连贯的工具。
```

## 检查

四格顺序清楚；角色和道具连续

四格按 1 至 4 展示检查、修理、挂起与轻响后的反应，人物发型、服装和黄铜风铃保持连续。首格聚焦桌上的木槌，深蓝纸签在后三格展示。未出现对白或额外人物。
