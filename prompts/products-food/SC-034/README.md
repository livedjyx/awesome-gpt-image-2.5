## 提示词

```text
使用输入图 1 的原创陶瓷花瓶作为唯一形状参考，制作横幅 3:2 的六色产品陈列棚拍。2 行×3 列均匀网格，恰好六只相同尺寸、相同轮廓、同一前视角的花瓶；保留输入中的细口、短颈、圆肩和收窄平底。按从左到右、从上到下依次使用奶油白、浅天蓝、鼠尾草绿、陶土橙、淡薰衣草紫、炭灰六种纯色釉。每只花瓶完整留在格位内，光线统一来自左上，底部软阴影一致，背景纯暖白。只改变釉色，不增加花枝、纹样、文字、标签、把手或第七只花瓶。
```

## 检查

产品形状相同；颜色数量准确

六只花瓶按两行三列排列，六种釉色可辨，瓶口、肩线与比例延续输入。
