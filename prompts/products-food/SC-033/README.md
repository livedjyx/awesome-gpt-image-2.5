## 提示词

```text
生成横幅 3:2 的青柠气泡水夏日广告摄影，无文字。一只透明高脚直筒玻璃杯位于中央偏右，杯中有气泡水、三块透明冰块和一片青柠。杯沿右侧向右上方扬起一弧清透水花，飞溅来自同一处水面，液体与杯口的前后遮挡连贯。左下角放一枚切开的青柠半果，淡青绿色纯净背景，逆侧柔光勾勒玻璃和水滴，留出左上空白。只有一只杯子，不让玻璃变形、液体穿墙或气泡像大珠子；不添加品牌、水印和文案。
```

## 检查

液体与杯体遮挡合理；飞溅方向统一

一杯气泡水、三块冰、一片杯内青柠与桌面半果对应提示词，水花与杯沿关系自然。
