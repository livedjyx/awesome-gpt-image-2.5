生成竖幅 2:3 的商业食物摄影分层爆炸图，主体是一份蘑菇烤蔬三明治。所有食材沿同一竖直轴分开悬浮，从上到下恰好六层：上片烤酸面包、烤蘑菇片、烤红甜椒、一片完整绿色生菜、一片浅黄奶酪、下片烤酸面包。层与层留出清楚空隙，保持三明治最终能上下对齐的大小和方向。奶油色背景，侧面柔光，面包气孔、蘑菇湿润感与蔬菜边缘真实清楚。没有标签、盘子、酱汁飞溅、重复面包或水印。 严格六层，生菜必须只有一片叶子、只有一层。六层之间只留五个空隙，不将生菜拆成上下两层。
