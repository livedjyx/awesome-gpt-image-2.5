```text
生成横幅 3:2 的晨雾湿地摄影。一条低矮木栈桥从左下方斜向延伸至画面中部，栈桥尽头是一片开阔水面，右侧成片芦苇，远处有淡淡树线。水面接近镜面，桥柱与芦苇的倒影各自在对应物体正下方，倒影随少量涟漪轻微破碎。晨光均匀柔和，浅金、灰绿与蓝灰色，近处木板纹理清楚，远处薄雾降低对比。桥面连续、不悬空，水面没有不对应的天空或物体。无人，无文字、过强太阳光斑或水印。
```
