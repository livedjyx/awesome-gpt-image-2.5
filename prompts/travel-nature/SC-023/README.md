## 提示词

```text
生成横幅 3:2 的真实植物微距照片。雨后的苔藓垫上有三根细长孢蒴柄，各自顶端带一只小孢蒴，前景叶尖悬着一滴清水。把清晰焦平面放在中央孢蒴和前方水滴附近，其他苔藓逐渐柔和虚化。侧后方柔光显出叶片薄度、柄的纤细质感和自然绿色层次。水滴反映邻近苔藓与光线，不出现完整倒置森林或夸张宝石折射。尺寸关系可信，没有昆虫、文字、图鉴标签或水印。
```

## 检查

清晰区集中；水滴折射不过度

三枚苔藓孢蒴和前景水滴清楚，焦点与背景散景分离，逆光叶缘可辨。
