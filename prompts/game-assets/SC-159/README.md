## 提示词

```text
绘制横幅 3:2 的九块苔原地形模块概念板，严格 3 列 3 行，等距三维视角。所有模块为相同宽高的方形地块，顶部菱形投影角度一致，厚度一致，淡灰背景且互不接触。按行展示：草地、积雪、碎石；低灌木、浅水塘、石径；冻土、枯木、营地火塘。模块上只用相应的简洁景物，没有人物；草地黄绿、雪冷白、石灰蓝，柔光方向统一。每块轮廓完整、物件不越出地块过多。不要文字、UI、水印。仅作关卡美术概念，不能暗示已经通过无缝拼接测试。
```

## 检查

视角一致；连接边需要实际拼接验证

九种苔原模块按三列三行呈现，菱形顶面投影与厚度接近，各类地貌可辨；未做引擎拼接验证。
