## 提示词

```text
制作一张横幅 3:2 的原创像素画道具图集，用于虚构园艺探险游戏的美术概念展示。暖浅灰底，整齐的 4 列×3 行布局，共 12 个等大格位，每格恰好一件完整道具。

按从左到右、从上到下的顺序依次绘制：绿色浇水壶、短柄小铲、木柄手耙、红柄园艺剪、卷起的麻绳、折叠植物标牌、装满土的小陶盆、蓝色喷雾瓶、带扣种子袋、棕色园艺手套一副、叶片形指南针、带提手的小收获篮。手套作为同一套道具成对放在一个格位内。

统一使用清楚可见的方形像素块、相同像素尺度、深色单像素感轮廓与有限色阶。道具都采用轻微俯视的前侧三分之四视角，光线统一来自左上方。每件道具四周保留相同安全边距，不越出格位，不与相邻道具相连。材质靠少量像素高光和阴影区分，像素边缘硬朗。

不要文字、编号、按钮、渐变背景、模糊抗锯齿、摄影纹理或水印。输出一张完整的图集概念图，不宣称可直接作为具有严格像素规格的游戏精灵表使用。
```

## 检查

像素尺度一致；每格道具完整

已逐格核对 4×3 布局的十二套道具、排列顺序与完整边界，手套一副占一个格位。像素块尺度在视觉上统一；结果为图集概念稿，没有执行像素对齐切片或游戏引擎导入测试。
