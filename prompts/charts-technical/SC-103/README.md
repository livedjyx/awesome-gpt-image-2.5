## 提示词

```text
绘制横幅 3:2 的图书归还检查流程图，清楚的科学示意风格，白底、深蓝线、浅绿圆角节点。标题「归还图书检查」。节点与连线严格如下：上方矩形「收到图书」向下连接菱形「是否破损？」；菱形左侧标「否」并连到左下矩形「登记归还」，再向下连「放回书架」；菱形右侧标「是」并连到右下矩形「登记维修」，再向下连「送交修补」。总计六个节点、五条单向箭头，分支不交叉，两条分支互不回连。文字逐字准确，字号一致，所有箭头清楚进入节点边缘。无额外节点、装饰图标或水印。
```

每条分支有去向；无凭空新增步骤

六个节点和五条箭头完整，「否」进入归还分支，「是」进入维修分支，没有多余连线。
