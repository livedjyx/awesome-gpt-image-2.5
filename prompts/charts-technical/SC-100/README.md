```text
绘制一张横幅 3:2 的技术线描结构概念图，主体是一台虚构的手摇削笔器。白色背景，深灰轮廓线、少量浅灰体积阴影与一处克制的蓝色强调，保持工程说明风格。

「1 前盖与进笔孔」
「2 滚刀组件」
「3 传动齿轮」
「4 后盖」
「5 摇柄」
「6 集屑盒」

前盖、滚刀组件、齿轮、后盖与摇柄沿主要装配轴从左前向右后排列；集屑盒放在下方，与削笔区相接。每条标签使用细引线准确指向对应组件，引线互不穿越文字。滚刀必须呈现削切用的斜向刀纹，不能画成电机或电池；摇柄与齿轮有可理解的连接。

左上角标题为「手摇削笔器结构」。右下角标注「概念示意，非工程制造图」。画面只包含这些文字与组件，不添加尺寸、公式、额外部件、装饰背景或水印。优先保证装配关系与标签对应。
```
