## 提示词

```text
绘制横幅 3:2 的六人协作关系图，原创虚构书展团队。白底、扁平科学示意风格，标题「书展协作图」，小字「虚构团队」。中央一个圆形节点「阿青」，外围五个圆形节点依次为「小禾」「林北」「木舟」「阿澄」「南枝」，共六人。中央分别向五个外围节点画一条无箭头直线，共五条线；外围节点之间没有连线。节点各配一个简洁几何头像，名字清晰且各出现一次。线从圆边出发，不穿过头像或文字；间距均匀，绿色和深蓝配色。不添加职责、数字、额外人物或水印。
```

## 检查

节点和边数量与给定清单一致

六个人名各出现一次，中央阿青连接五个外围节点，共五条无向线，未出现外围互连。
