## 提示词

```text
生成横幅 3:2 的自然写实直闪抓拍。旧书仓库打烊后，两位虚构成年朋友并肩坐在木箱上，一人穿酒红毛衣、一人穿灰色连帽衫，手里各拿一本合拢的无字旧书，笑着看向镜头。背后为堆叠书箱和半开的铁门。相机闪光从镜头附近正面照亮人物，墙上短而清楚的投影方向一致，背景稍暗。保留随手拍略偏的构图、真实皮肤与纸箱质感，头顶与手完整入画。恰好两人，两本书，不出现可读书名、品牌、水印或额外手臂。
```

## 检查

闪光方向统一；保留随手拍构图

两位成年人物和两本书数量正确，正面闪光、背景压暗及纸箱质感清楚。背景出现未指定的英文小告示，不影响直闪主体；复用时可进一步约束背景文字。
