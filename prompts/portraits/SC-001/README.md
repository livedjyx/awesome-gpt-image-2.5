```text
使用输入图 1 作为唯一的人物身份参考，生成一张自然写实的陶艺工作室职业肖像，竖幅 2:3。

保留同一个人的脸型、五官比例、短卷黑发、细圆框眼镜、自然雀斑与成年年龄感。人物位于画面中部偏右，从腰部以上入画，身体微微转向左侧窗户，头部转回镜头，神情平静而亲切。白色上衣外加一条干净的灰蓝色陶艺围裙，双手自然搭在工作台前缘。

```
