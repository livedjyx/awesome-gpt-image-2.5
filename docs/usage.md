# 使用提示词

从首页进入分类，或直接打开[配图浏览](gallery.md)。先查看结果图和使用场景，再复制条目中的完整提示词。生成记录与检查结果可从条目底部查看。

| 类型 | 使用方式 |
|---|---|
| G：直接生图 | 复制提示词，补齐条目要求的文案或数据 |
| R：参考图引导生成 | 按顺序上传输入图，用图片提供身份、结构或布局 |
| E：编辑现有图片 | 上传待编辑图及其他素材，按提示词修改指定内容 |

输入图和结果图分别展示。替换输入人物、产品或场景后，应重新检查结果；条目的验证记录对应页面展示的那次生成。

`prompt.md` 保存与结果图对应的实际提示词。文字、数字、尺寸或模型参数不应在没有重新生成和复核的情况下修改。模型设置与提示词分开记录，页面只显示实际使用过的设置。

首页统计已配图数量和通过视觉检查的图库案例数量。标为「规划中」的选题只提供制作方向；已有条目可以直接查看提示词和对应图片。
