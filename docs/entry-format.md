# 条目规范

选题编号使用 `SC-001` 形式，分配后不复用。每个选题归入一个主分类；风格独立记录。目录登记在 [catalog.json](../data/catalog.json)，分类路径登记在 [categories.json](../data/categories.json)。

## 文件结构

```text
prompts/<category>/SC-001/
├── entry.json
├── prompt.md
├── README.md
└── images/
    ├── input-01.png
    ├── input-02.png
    └── result-01.png
```

`entry.json` 保存生成与审核记录，按 [entry.schema.json](../schemas/entry.schema.json) 检查。`prompt.md` 保存本次实际提交的纯提示词正文，不加 Markdown 标题或代码围栏。`README.md` 由目录脚本生成，用于浏览与复制提示词。

直接生图不需要 `input-*` 文件。模板放在 [templates](../templates/README.md)，模板目录不计入条目数量。

## 记录字段

| 字段 | 内容 |
|---|---|
| `id` | 已登记的选题编号 |
| `status` | `draft`、`generated` 或 `verified` |
| `prompt_file` | 固定为 `prompt.md` |
| `inputs` | 按模型接收顺序记录图片路径、用途及 SHA-256 |
| `result` | 对应输出图的路径及 SHA-256；草稿阶段可为 `null` |
| `generation` | 实际模型标识、模型是否已确认、使用入口、生成时间、参数、提示词 SHA-256 |
| `review` | 审核者、审核时间、检查结果及备注；待审核时可为 `null` |

`generation.parameters` 仅记录实际使用的非敏感设置，例如界面可见尺寸。未确认的参数不填；禁止写入密钥、认证请求头、令牌和本机文件路径。没有确认模型标识时，`model` 为 `null`，`model_confirmed` 为 `false`，条目不能标为已验证。

正式图库要求实际确认的模型属于 `gpt-image-2.5` 命名系列。页面显示真实标识；如果使用入口无法提供可确认的模型标识，保留待审核状态。

哈希按文件原始字节计算。图片、提示词、输入顺序或实际设置发生变化后，要重新生成并审核。已验证记录描述一次具体结果，不表示所有替换场景都通过测试。

`prompt.md` 使用 UTF-8 无 BOM 编码和 LF 换行。先保存最终正文再计算哈希，避免 Git 在不同系统上规范化换行后导致记录失效。

## 输入与输出图片

图片与条目同目录，避免远程图片链接失效。使用 PNG、JPEG 或 WebP；扩展名与实际文件格式应一致。命名只使用 `input-01`、`input-02` 与 `result-01`，编号对应记录顺序。

输入图应说明提供的是身份、姿态、产品、布局还是待编辑画面。R、E 必须具备完整输入图，输入数量与目录登记一致。输出图使用对应提示词和输入实际生成；拼图、漫画和多视图任务可用一张完整多格图作为结果图。

发布前检查图片方向、色彩、文件体积、文字可读性和图像元数据。去掉不需要公开的定位、设备和个人信息。保留作品本身需要的内容，不用占位图或其他成图代替实际结果。

## 审核状态

| 状态 | 最低要求 | 展示方式 |
|---|---|---|
| 规划中 | 只有目录选题，没有条目文件 | 分类选题表 |
| 草稿 `draft` | 已建立条目，尚在准备文字或素材 | 计入草稿，不能列入图库 |
| 已生成待审核 `generated` | 提示词、所有输入和对应结果齐全；生成记录与文件哈希一致 | 分类标明待审核 |
| 已验证 `verified` | 生成要求全部满足，模型已确认，审核检查通过 | 正式图库与已发布统计 |

审核至少涵盖：提示词要求、视觉风格、图片可读性、文字与数量准确性、参考图保持、修改范围。条目不涉及的检查可记为 `na`，文字与数量检查需说明不适用原因。参考任务须通过输入保持检查；E 还须通过修改范围检查。

图表、教学内容、特殊投影和可拼接资产应在备注记录各自的核验内容。脚本能检查文件与记录的一致性，视觉质量和知识准确性由审核者检查。

## 构建与校验

```shell
python -m pip install -r requirements-dev.txt
python scripts/catalog.py build
python scripts/catalog.py check
python -m unittest discover -s tests -v
```

`build` 先校验内容，再更新首页、分类页面、条目页面和图库索引。`check` 同时检查内容与生成文件是否同步，不改写文件。编号、图片、模型或审核信息不满足要求时，命令返回非零退出码。
